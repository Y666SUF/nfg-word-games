NFG Words — Mac + iOS build
============================

## Folder layout

  ~/Documents/nfg-word-games/   Python server + ios/NFGWords Xcode project
  ~/Documents/nfg-crash/        NFG platform (proxies Word Games to y666suf.com)

## Pull latest

```bash
cd ~/Documents/nfg-word-games
git pull origin main

cd ~/Documents/nfg-crash
git pull origin main
```

## Production server URL (baked in)

`ios/NFGWords/Config/GameServerConfig.swift` → `serverURL = "https://y666suf.com"`

Bundle ID: `com.yusufali.nfgwords`  
Display name: **NFG Words**

## Open and run on iPhone

```bash
open ~/Documents/nfg-word-games/ios/NFGWords.xcodeproj
```

1. Select your physical iPhone in the toolbar.
2. Product → Run (⌘R).

## Test flow

1. Choose username (profanity-filtered).
2. Play WordWheel.
3. Open **Ranks** — loads `https://y666suf.com/api/word-games/leaderboard`.

Windows PC must be running:

```powershell
cd C:\Users\Yusef\Documents\nfg-crash
git pull origin main
.\run-electron-cloudflare.bat
```

Verify:

```bash
curl https://y666suf.com/api/word-games/health
```

## Mac-only dev server (optional)

```bash
cd ~/Documents/nfg-word-games
./run_server.sh
curl http://127.0.0.1:19877/api/word-games/health
python3 scripts/test_server.py
```

For LAN iPhone testing: temporarily set `GameServerConfig.serverURL` to your Mac IP
(e.g. `http://192.168.1.x:19877`), rebuild, then revert to `https://y666suf.com`
before App Store / production.

See also: `docs/HOSTING_LIKE_NFG_CRASH.txt`
