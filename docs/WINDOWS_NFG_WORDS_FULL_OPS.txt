### G) Shared scoring (iOS — no server change required)

Scoring is **client-side** and synced via `PUT /api/word-games/players/{id}/scores`.

Both games use the same scale (`GameScoring` in iOS):

| Action | Points |
|--------|--------|
| WordWheel bonus word | `(wordLength - 2) × 2` |
| WordWheel puzzle word / **Wordwich solve** | `(wordLength - 2) × 10` |
| Wordwich: each **new** correct prefix letter (your guess only) | `+5 per letter` |
| Wordwich: wrong / unhelpful guess | **0** |

Examples (answer **fire**):
- Guess `drink` → **0** (no prefix match)
- Guess `fare` → **5** (reveals F)
- Guess `fine` → **5** (reveals I → prefix now FI; only the new letter pays)
- Solve `fire` → **5** (reveals R) + **30** solve = **35**

Per-game leaderboard scores are **cumulative** (fair across WordWheel and Wordwich).
Overall leaderboard uses `totalScore` across all games.

### H) Wordwich gameplay rules (server + iOS)

- Target word length is **hidden** — only `revealedPrefix` is sent (e.g. `FI`)
- Letters reveal **prefix-only, left-to-right** (fare vs fire → only F green, not E)
- 5 closest guesses alphabetically **below** answer shown above; 5 **above** shown below
- Multiplayer: shared round; guesses POST immediately; clients poll every ~2s
