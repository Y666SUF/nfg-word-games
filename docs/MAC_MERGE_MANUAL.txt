```bash

git fetch origin main
git log --oneline HEAD..origin/main
git log --oneline origin/main..HEAD

git pull origin main --no-rebase --allow-unrelated-histories -m "Merge GitHub main with standalone NFG Word Games"
```

If you see `refusing to merge unrelated histories`, you forgot `--allow-unrelated-histories`.
Or use force push: `docs/MAC_FORCE_PUSH.txt`

If Git opens an editor for a merge message, save and close (`:wq` in vim).

## Common mistakes

1. Do NOT paste comments into git commit:
   WRONG:  git commit -m "message"  # if there are changes
   RIGHT:  git commit -m "message"

2. Do NOT force push unless you intend to wipe GitHub history:
   git push --force origin main   ← only if you know you want this
