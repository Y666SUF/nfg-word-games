### Summary of what changed (server-relevant)

#### Wordwich (IMPORTANT — server must update)
- **Auto-reset after correct guess**: `wordwich_round.py` now starts a **5-second** celebration window, then automatically starts a **fresh round** for all online players on the next API poll. No client has to call `POST /rounds` anymore.
- New API fields on round state: `newRoundIn` (countdown seconds), `solvedAnswer` (revealed word when won).
- `wonAt` timestamp stored when someone solves the word.
- Solo/Online mode, family-friendly filters, UK spellings, expanded dictionary (~97k words).
- Admin reset still at `POST /api/word-games/wordwich/reset` (admin player ID only).

#### WordWheel (server data + API)
- **2000 bundled levels** in `data/wordwheel-levels.json` (v9, `proceduralFromLevel: 2001`). Levels 2001+ are **iOS-only** procedural — server just serves the bundled JSON.
- UK-preferred dictionary ~42k words (`data/english-dictionary.json` v8).
- `wordwheelTimed` added to `GAME_IDS` — separate timed-mode leaderboard.
- `GET /api/word-games/wordwheel/levels` serves bundled levels.
- `data/sensitive-word-blocklist.json`, `data/bonus-round-packs.json` added.
- `scripts/word_filters.py` — UK spelling preference + content filters.

#### Server (`server.py`)
- Leaderboards for `wordwheel`, `wordwheelTimed`, `wordwich`, `hangman`.
- Wordwich routes under `/api/word-games/wordwich/*`.
- Player login, score sync, profanity filter.

#### iOS-only (no Windows action needed)
- Progressive wheel: **4 letters around centre** at start, +1 every **150 lifetime clears**, max **10 around** (+ centre).
- NFG Coins, hints, bonus crossword rounds, Timed WordWheel UI.
- Procedural infinite levels after 2000.
